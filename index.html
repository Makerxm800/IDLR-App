Downloads
Auto-detect URL
Watch what you paste and set Mode + Format for it — a Spotify track goes to Audio/MP3, a YouTube playlist goes to Playlist mode. Turn it off and the detector still tells you what it saw, but your own choices stay untouched.
Link Preview
Fetches the title, uploader and cover from the page so you can see what you are about to grab. One request to that site, only when a link is pasted.
Download Thumbnail
Saves the cover image and embeds it in the audio file, so a downloaded track shows artwork in your player. Turning it off makes each download slightly quicker.
Full Playlist
When a playlist link is pasted, download every item in it, not just the first. A 200-track playlist really will queue 200 downloads, so leave this off if you only ever want the single video you linked.
Alerts
Download Alerts
Adds a result to the bell list when a download finishes or fails, and sends a system notification too when your browser allows it (see below). Nothing leaves this device.
System notifications
Asking the browser is optional — the bell list always works
Interface
Liquid Glass
Frosted blur behind panels. It is a paint cost, so switching it off is the honest fix for a slow machine or an old integrated GPU.
Hero Animations
The title and the Sites chip animate in when the page opens. Pure decoration — off means the words are simply there.
Calm Motion
Removes sliding, scaling and pulsing everywhere, for motion sensitivity and for screen-reader use. This wins over Hero Animations if both are set.
Console Log
The live yt-dlp output under the progress bar. When a download fails, this is where the real error is — leave it on while debugging, turn it off for a quieter window.
Confirm Before Delete
Ask once before clearing history or emptying the trash. Deleted rows go to Trash rather than being erased, so this is about the extra click, not about data loss.
